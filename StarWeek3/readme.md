# Bookmarker

A bookmarking website built using HTML, CSS and JS

Through this website, you can save your favorite websites and visit them later or remove them

## Features

- Clean and semantic HTML
- Design and layout using Tailwind CSS
- DOM Manipulation using Javascript

## Tech Stack

- HTML5
- Tailwind CSS
- Javascript

## Project Structure

```

      ├── index.html
      └── script.js
```

## How to run

1. Clone the repository
2. Open ‘index.html’ in your browser
