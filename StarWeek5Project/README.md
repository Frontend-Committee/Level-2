# ThoughtsInPlace

A blog app built using React and TailwindCSS
On this website you can check out blog posts and read them

## Features

- Clean JSX code
- Design and layout using TailwindCSS
- Event and state handling using React

## Tech Stack

- React.JS
- TailwindCSS

## Project Structure

```
├── index.html         
└── src/          
    ├── main.jsx 
    ├── App.jsx   
    └── index.css
```
