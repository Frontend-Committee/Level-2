# # Instagram Clone

A clone of the instagram website using HTML and CSS.

It shows a main page with posts and stories and pages for reels,messages,search and a personal profile.

## ## Features

- Clean and semantic HTML
- Design using CSS
- UI layout using Flexbox, and Grid

## ## Tech stack

- HTML5
- CSS3
