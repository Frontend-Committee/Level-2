# Student Task and Grade Manager

A task manager website built using HTML, CSS and Javascript

It allows for an admin to add students and their grades and check who passed

## Features

- Clean and semantic HTML
- Modern UI Layout
- DOM Manipulation using Javascript

## Tech Stack

- HTML5
- CSS3
- Javascript

## Project Structure

```

      ├── index.html
      ├── style.css
      └── script.js
```

## How to run

1. Clone the repository
2. Open ‘index.html’ in your browser
